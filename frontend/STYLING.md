# 样式约定

- 页面和组件使用 Tailwind 4 工具类；共享类通过 `cn` 或 `cva` 组合，保持类名静态可扫描。
- `src/styles/globals.css` 只承载 Tailwind 入口、主题变量和字体声明，不添加页面选择器或组件样式。
- 深色模式、响应式、悬停、焦点和 Base UI 状态通过 Tailwind 变体表达。精确像素、字幕描边和滑块伪元素使用任意值与任意变体。
- 连续变化的运行时数值（音量、拖动位置、字号、测量高度）可以通过动态属性传给 Tailwind 工具类；Motion 保留动画插值。
- `bun test` 包含样式边界检查。更改样式后，检查文译、同传、字幕、用户菜单、深浅色和响应式布局，并运行 `wails build`。
