# 截图功能

Windows 桌面版可点击悬浮工具栏或工作区右上角的剪刀按钮，也可在其他应用中按 **F1** 开始截图。

- 进入截图时默认预览任务栏之外的整个工作区，不自动保存或置顶。拖动选择矩形区域，松手即显示标注工具栏；不需要二次确认。边框向内绘制并加粗，贴近屏幕两侧也能看到；绘制时与刚画完时不显示控制点，单击选区后才显示八个控制点供调整。工具栏跟随选区，并自动避让屏幕边缘。
- 矩形、圆形支持调整大小及七种颜色，绘制过程中和刚画完时不显示控制点，取消当前工具后单击已有图形才显示控制点。箭头从鼠标按下的位置指向松手的位置，不显示缩放控制点；支持颜色及小、中、大三种粗细，使用实心圆点直接选择。选择文字工具后单击选区即可输入，输入时显示虚线矩形，完成后虚线消失；支持颜色及小/中/大字号，三档按钮直接选择；Enter 换行，单击框外完成输入。输入框随内容自动增高，不显示滚动条。
- 再次点击当前工具图标可取消该工具；没有启用绘图工具时可直接选择标注并移动。颜色、字号、粗细选项属于各自工具，仅在使用对应工具时出现在主工具栏下方，不再显示全局配置栏。退出按钮与其它图标始终在同一主工具行。Delete 删除选中的标注。Ctrl+Z 撤销、Ctrl+Y 或 Ctrl+Shift+Z 恢复选区和标注操作，包括添加、移动、缩放、删除及样式修改；新操作会清空恢复分支。滚动拼接切换到新的长图后重新记录编辑历史。
- 保存按钮导出包含标注的 PNG。置顶按钮将截图作为可拖动的桌面贴图显示；右上角叉号或 Esc 关闭贴图并恢复原来的窗口。
- 翻译按钮仅占位，尚未实现翻译。
- 滚动截图每点击一次向选区下方的应用滚动并追加一屏，自动去除重叠部分；到达底部或无法匹配时给出提示。请框选实际可滚动的内容区域，避开浏览器地址栏、侧栏、固定导航及动态视频。完成滚动后再标注更方便。长图最大高度 30000 px。
- 当前截取主屏幕，一次编辑或置顶一张截图。F1 被其他应用占用时会在应用日志中记录注册失败，工具栏入口仍可用。

## 功能验证

先运行 `bun run dev -- --host 127.0.0.1`，打开 `/tests/screenshot-harness.html`，在浏览器开发者工具中执行：

```js
await (await import('/tests/screenshot-functional.js')).runScreenshotFunctionalTests()
```

该场景使用真实浏览器的 SVG、Canvas、PointerEvent 和 React 交互，模拟桌面桥接以覆盖默认工作区预览、无确认框选、调整尺寸、全部标注工具、虚线文字输入、撤销/恢复、颜色/字号/粗细、PNG、滚动入口、置顶及取消。原生截图与 F1 必须用 `wails build` 后的桌面程序验证。滚动图像去重与接缝另有 `TestScrollingScreenshotStitchesOnlyNewContent` 场景测试。
